## 5. 0.2.5에서 새 사례가 보이지 않던 문제

- 매체: v0.2.5-pilot.20261111(태그 1b7fd8f)에 W01~W60 JSON·그림·ZIP이 들어 있다(설치 리허설 a18에서 확인).
- 화면: 0.2.5의 왼쪽 메뉴와 메뉴 검색에 "분석 사례집"이 **없었다**. 홈 단추로만 들어갈 수 있었고, 조사에서 연 C 사례 상세에서는 W 영역이 숨겨졌다. 0.2.5 운영 절차 문서가 "왼쪽 메뉴"라고 잘못 안내했다.
- 열어 둔 화면은 업데이트 뒤에도 이전 화면 파일로 동작한다.
- 고친 것(이 브랜치, 매체 미반영): PR #14 병합(메뉴 검색·C 사례 상세에서 진입), 시나리오의 "분석 예시"와 도구·설정에서 진입, 버전 표시와 새로 고침 안내, 사례 파일이 일부만 있을 때 알림, 매체에 화면 버전 파일 포함.
- **설치본에 반영되려면 이 브랜치로 새 매체를 만들고 업데이트를 검증해야 한다. 아직 하지 않았다.**
