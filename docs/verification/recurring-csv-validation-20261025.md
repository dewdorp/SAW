## OpenSearch namespace·예약 열 후속 수정

전체 r1은 기존 built-in namespace 검사 `test_extension_template_preserves_known_typed_namespaces`에서 실패했다. 실행 중 소스 변경이 없었고 단일 회귀에서도 재현했다. `security_csv`를 명시적 object namespace 목록에 추가하고, 원천 `csv_format`/`source_columns` 예약 열이 있으면 원문 열 사전을 일관된 object 형태로 보존하도록 수정했다. 원천 문자열을 검증된 숫자 카운터로 승격하거나 기존 보관 세대를 자동 재매핑하지 않는다.

빈/공백뿐인/점이 든 열 이름은 전용 파서가 거부하고 지원되는 평평한 추가 이름은 기존199열 상한 안에서 보존한다. 원문을 임의로 이름 변경·삭제하지 않으며 미지원 헤더가 일반 CSV로 처리될 수 있다는 점을 안내한다. 수정 후 독립 지정 범위 재검토에서 미해결 중요/치명 지적이 없었다. 이 판정은 최종 전체 서버·매체 인수 성공 판정과 구분한다.
