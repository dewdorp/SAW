## 4. 확인하지 못한 것

- **브라우저**: 로그인한 실제 브라우저 확인은 하지 않았다. 화면은 React/jsdom 자동 시험으로만 확인했다.
- **대용량**: 10만·100만 건 성능을 다시 측정하지 않았다. PPA-03의 처리 시간 단축 효과는 미측정이다.
- **OpenSearch·PostgreSQL**: native 환경 시험은 하지 않았다. 반열린 시간 창은 OpenSearch 질의 변환만 바꿨고 실제 실행은 미확인이다.
- **설치 매체**: 새 매체의 실제 설치·업데이트·복구 리허설은 하지 않았다. 대상 Windows 10 Enterprise LTSC 2019 x64 build 17763 검증은 `PENDING_ENV`다.
- **기존 저장 자료**:
  - 이미 저장된 FW 관측 기록에는 새 `whole_session` 표시가 없다. 재처리하면 반영된다.
  - 이전에 저장한 골든 버전에는 원천 목록(provenance)이 없다. 조회할 때 근거 참조와 조사 ID로 권한을 재검사한다.
- **운영 서버**: 실제 업데이트는 실행하지 않았다.
