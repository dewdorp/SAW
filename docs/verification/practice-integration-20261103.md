# 가상 로그 예제 통합 검증 (2026-11-03, 2026-11-04 보완)

기준: v0.2.3(PR #8, abd0ddf) 위 PR #9(b3e02a8, 가상 로그 예제)를 가져와 통합했다. 이후 PR #10(2c5c524, 읽기 쉬운 작업대) 위 브랜치 `claude/incident-readable-20261103`로 옮겼다. 합성 자료와 격리 시험 설치만 사용했고 운영 자료·실제 계정·기존 v0.2.3 매체·태그는 바꾸지 않았다. 이 릴리스 전체의 검증 결과는 [읽기 쉬운 작업대·예제 확장 검증](readable-workbench-20261104.md)을 따른다.

## 1. PR #9 검토

- 범위: 홈·조사의 "가상 로그 예제" 경로(/practice), 사례 20개(초기 20 + 독립 후속 80 = 100문항), 문항마다 보기 4개(정답 1·오답 3)와 해설, 원본 NDR·FW CSV 40개(6,216행), 릴리스 빌더의 예제 CSV 복사·누락/불일치 거부.
- 연습은 서버에 쓰지 않는다(정적 웹 자산). 조사·통계·골든셋에 합성 자료를 등록하지 않는다.
- PR 시험: 서버 73건(예제 근거·매체 복사·매체 목록), 화면 3파일 12건 통과.
