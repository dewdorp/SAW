# 가상 로그 예제 통합·0.2.4 검증 (2026-11-03)

기준: v0.2.3(PR #8, abd0ddf) 위 PR #9(b3e02a8, 가상 로그 예제)를 브랜치 `claude/practice-integration-20261103`에 그대로 가져와 통합했다. PR #9의 예제 콘텐츠·화면·매체 복사는 다시 만들지 않았다. 합성 자료와 격리 시험 설치만 사용했고 운영 자료·실제 계정·기존 v0.2.3 매체·태그는 바꾸지 않았다.

## 1. PR #9 검토

- 범위: 홈·조사의 "가상 로그 예제" 경로(/practice), 사례 20개(초기 20 + 독립 후속 80 = 100문항), 문항마다 보기 4개(정답 1·오답 3)와 해설, 원본 NDR·FW CSV 40개(6,216행), 릴리스 빌더의 예제 CSV 복사·누락/불일치 거부.
- 연습은 서버에 쓰지 않는다(정적 웹 자산). 조사·통계·골든셋에 합성 자료를 등록하지 않는다.
- PR 시험: 서버 73건(예제 근거·매체 복사·매체 목록), 화면 3파일 12건 통과.
