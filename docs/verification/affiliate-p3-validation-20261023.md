# P3 검증 — 후속확인과 고정 보고서

P3 구현·검토 수정 후 코드를 동결하고 전체 서버 회귀시험까지 완료했다. 이 문서는 새 릴리스나 운영 인수 완료 기록이 아니다.

## 구현 범위

- CheckRevision과 FollowUpVersion으로 요청·회신·검증·재개를 각각 기록한다. 담당자와 기한은 선택 사항이며, 변경 충돌 시 입력을 보존한다. 자료 부족은 정상 판정이 아니다.
- 보고서 v2는 선택한 조사·분석 실행·확인·후속확인의 정확한 버전을 고정한다. 기존 v1 내용과 지문은 다시 쓰지 않는다.
- 같은 고정 내용을 HTML과 Excel 8개 시트로 내보낸다. 단일 조사, 선택한 후속확인, 조사 목록의 선택 다중 조사를 지원한다.
- 요약에는 관측·판단·후속 확인과 단위·자료 한계를 먼저 보인다. 상세 구조와 원문 참조는 보존한다. 서로 다른 장비 입력 건수나 고유수를 무조건 합산하지 않는다.
- 내보내기는 제한된 Job으로 생성하고 취소·재시도·저장·다운로드를 연결한다. 원천 자료 권한을 제출·게시·다운로드 때 검사한다.

## 실제 실행

- 전용 합성 브라우저58373에서 일반 로그인/MFA, 요청v1→회신v2→자료부족 검증v3→정확 버전 선택→Excel 작업 완료·다운로드와 저장 HTML을 확인했다. 사용자 운영 계정이나 은행 자료는 사용하지 않았다.
- 최종 다운로드 권한 수정 후 서버를 재시작해 저장 HTML과 Excel을 다시 열었다. 최신 실제 파일은129,766바이트, SHA256 `3a41feb213f680b2a0499411e814961ff7f8341f418a742ee46c846f2c8aed0a`다.
- 실제 XLSX ZIP/XML에서 요약·상세·확인 필요·통계·시간 추이·근거·적용 기준·범위·한계 8시트, 읽기용 요약, 숨긴 상세 열, 외부 링크·매크로 미포함을 확인했다. Office 또는 LibreOffice 화면 렌더링은 확인하지 않았다.
- 실제 PostgreSQL16.15/OpenSearch2.19.6/Nori에서13통과·0실패·0건너뜀, 시험143.532초·전체411.593초. 새 스키마와0018→0020 보존 이관, FW 업로드, 후속확인 버전/원천 권한, 다중 보고서와 실제 XLSX, 보고서 보존·삭제를 검사했다. 공개 런타임23,195파일 재대조 후 새 전용 데이터/설정으로 실행했고, 정상 종료·소유 시험 포트 닫힘을 확인했다.

## 실패·중단 이력

- 이전 전체r1은2006통과/9실패/6건너뜀이다. 실행 중 writer 수정이 겹친 KeyError 실패를 기록하며 후속 결과로 과거 실행을 통과로 바꾸지 않는다.
- r2와r3는 최종 수정 필요로 중단했다. 완료한 전체 회귀 결과가 아니다.
- 이전 실제 저장소 시험은12통과/1실패였다. 긴 경로의 WinError3를 일반/extended 경로로 대조해 원인을 확인한 후 위13개를 새 환경에서 다시 수행했다.
