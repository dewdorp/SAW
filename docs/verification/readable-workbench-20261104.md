기준: PR #10(2c5c524, 읽기 쉬운 작업대, PR #9 위)에 브랜치 `claude/incident-readable-20261103`로 분석가 검토 요청을 반영했다. 합성 자료·격리 QA 설치만 썼다. 운영 서버·운영 자료·실제 은행 자료(`var/objects`, `INV-20261008-001`)·기존 v0.2.3 매체와 태그는 바꾸지 않았다.

## 2. 추가 확인 요청

| 요청 | 반영 | 확인 방법 |
|---|---|---|
| 초안 바로 열기 | "추가 확인 요청"이 자동 관측 기록을 연결하고 ④의 요청 초안을 엶. 등록·발송하지 않음 | 화면 시험 |
| 늦은 자동 채움 | 분석가가 아직 고치지 않은 칸만 채움. 먼저 입력한 질문을 덮지 않음 | 화면 시험(응답 지연 재현) |
| 초안 보존 | 원문을 보고 돌아와도 유지. 다른 확인 기록으로 새 초안을 시작하면 먼저 물음 | 화면 시험 |
| 상태 구분 | 작성 중 · 등록 전 / 요청 등록 · 회신 대기 / 회신 수신 · 검증 전 / 검증 완료 | 화면 시험 |
| 대상 요약 | "출발지 1개 → 목적지 8개 · 포트 443 · 기간", 연결 목록은 펼침. 대상은 표본 20건이 아니라 계산한 그룹 전체(연결 200개 한도). 표본·한도 초과·주소 없는 기록이 있으면 "그룹 전체가 아닙니다". 칸에 담긴 주소가 그룹보다 적으면 경고 | 서버·화면 시험 |
| 연결 대조 | 요청 연결과 회신 연결을 하나씩 맞춤: "요청한 연결 2개 중 0개 일치"(불일치), 목록만 있으면 "개별 연결 미확인"(일부), 모두 맞으면 일치. 회신 화면에 연결 입력 칸 추가 | 서버·화면 시험 |
| "정기 점검" 회신 | 범위 없는 회신은 범위 미기재로 남고 "확인됨" 검증·"정상" 종료가 거부됨 | 서버 시험 |
| 반복 통신의 포트 없는 기록 | 포트 미기록 그룹을 따로 계산(20초 간격 8건 → "포트 미기록") | 서버 시험(SQLite 저장소) |

## 3. 가상 로그 예제 확장

## 5. 실제 브라우저 (격리 QA, 합성 자료, 사용자가 직접 로그인한 합성 계정 manager)

- 업로드: 가상 예제 C010의 NDR·FW CSV 2개를 새 조사(가상 한빛금융 9347)로 올림 → 전용 파서 en_ndr_http_csv 140건·en_fw_csv 164건, 실패 0.
- 1366×768: 자료 요약 한 줄("가상 한빛금융 9347 | 2026년 9월 5일 ~ 10월 10일 (기록 기준) | 방화벽(FW) 164건 · NDR HTTP 140건 | 전체 304건")과 첫 활동 행(제목·근거 줄)이 첫 화면에 보임. 확인 중 첫 행이 화면 아래에 걸쳐 짧은 화면용 배치를 줄였다.
- C010 재현: 민감도 높음 → "10.31.1.30에서 약 1분 동안 목적지 8개의 TCP 443 포트에 접촉했습니다." 펼침 → 근거 24건(시각·출발지·목적지·포트·처리 결과·장비·로그 종류 열) → ① 전체 현황 복귀 시 민감도 높음·같은 후보 펼침 유지.
- 추가 확인 요청: ④에 초안이 바로 열림("작성 중 · 등록 전", "출발지 1개 → 목적지 8개 · 포트 443", "계산한 그룹 전체: 기록 24건 · 연결 8개"). 질문을 고친 뒤 ③ 전체 로그를 다녀와도 고친 내용 유지. 등록된 후속확인 0건(자동 보관은 등록하지 않음).
- 640px: "검토할 활동으로 이동"이 활동 목록으로 이동·초점 이동, 가로 스크롤 없음. 밝은 화면에서 읽힘, Tab으로 활동 행 초점 표시, Enter로 펼침.
- 가상 로그 예제: "예제 100개 · 추가 자료 400가지", 검색("9시간" → 5개), C086 풀이 → 정답·판단 근거(fw.csv 130·131·134행)·다른 보기 해설·추가 자료 단추.
- 확인 중 고친 것: 원문 표 시각에 연도·소수 초 표시(예: 2026-10-10 09:00:00.2), 검색 기간 문구, 자동 질문의 "…했습니다.에서" 문장 어색함, 대상 요약에 요청 기간 표시, 1366×768 첫 활동 노출.

## 6. 경계(미검증·제한)

- 대상 Windows 10 Enterprise LTSC 2019(17763) 설치, 관리자 서비스·재부팅: 이 개발 PC에는 해당 환경이 없다(PENDING_ENV).
- native OpenSearch: 포트 없는 반복 통신 그룹은 OpenSearch의 묶음 집계가 빼므로 나타나지 않는다(SQLite 저장소에서는 나타남). 확인 요청의 전체 그룹 대상은 범위 전체 건수를 따로 세어 "그룹 전체가 아닙니다"로 표시한다. native OpenSearch 실행 시험은 이 PC에서 건너뛴다.
- 초안 보관은 그 브라우저 화면 안의 임시 보관이며, 새로 고침·다른 PC에서는 남지 않는다.
- 대용량 관측창·내보내기 시간, 운영 서버 업데이트는 하지 않았다.
