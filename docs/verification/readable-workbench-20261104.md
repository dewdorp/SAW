## 2. 추가 확인 요청

| 요청 | 반영 | 확인 방법 |
|---|---|---|
| 초안 바로 열기 | "추가 확인 요청"이 자동 관측 기록을 연결하고 ④의 요청 초안을 엶. 등록·발송하지 않음 | 화면 시험 |
| 늦은 자동 채움 | 분석가가 아직 고치지 않은 칸만 채움. 먼저 입력한 질문을 덮지 않음 | 화면 시험(응답 지연 재현) |
| 초안 보존 | 원문을 보고 돌아와도 유지. 다른 확인 기록으로 새 초안을 시작하면 먼저 물음 | 화면 시험 |
| 상태 구분 | 작성 중 · 등록 전 / 요청 등록 · 회신 대기 / 회신 수신 · 검증 전 / 검증 완료 | 화면 시험 |
| 대상 요약 | "출발지 1개 → 목적지 8개 · 포트 443 · 기간", 연결 목록은 펼침. 대상은 표본 20건이 아니라 계산한 그룹 전체(연결 200개 한도). 표본·한도 초과·주소 없는 기록이 있으면 "그룹 전체가 아닙니다". 칸에 담긴 주소가 그룹보다 적으면 경고 | 서버·화면 시험 |
| 연결 대조 | 요청 연결과 회신 연결을 하나씩 맞춤: "요청한 연결 2개 중 0개 일치"(불일치), 목록만 있으면 "개별 연결 미확인"(일부), 모두 맞으면 일치. 회신 화면에 연결 입력 칸 추가 | 서버·화면 시험 |
| "정기 점검" 회신 | 범위 없는 회신은 범위 미기재로 남고 "확인됨" 검증·"정상" 종료가 거부됨 | 서버 시험 |
| 반복 통신의 포트 없는 기록 | 포트 미기록 그룹을 따로 계산(20초 간격 8건 → "포트 미기록") | 서버 시험(SQLite 저장소) |

## 6. 경계(미검증·제한)

- 대상 Windows 10 Enterprise LTSC 2019(17763) 설치, 관리자 서비스·재부팅: 이 개발 PC에는 해당 환경이 없다(PENDING_ENV).
- native OpenSearch: 포트 없는 반복 통신 그룹은 OpenSearch의 묶음 집계가 빼므로 나타나지 않는다(SQLite 저장소에서는 나타남). 확인 요청의 전체 그룹 대상은 범위 전체 건수를 따로 세어 "그룹 전체가 아닙니다"로 표시한다. native OpenSearch 실행 시험은 이 PC에서 건너뛴다.
- 초안 보관은 그 브라우저 화면 안의 임시 보관이며, 새로 고침·다른 PC에서는 남지 않는다.
- 대용량 관측창·내보내기 시간, 운영 서버 업데이트는 하지 않았다.
