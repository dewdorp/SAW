## 실제 HTTP·브라우저

기존 합성 전용 로컬 데모를 새 코드/빌드로 시작했다. 테스트 계정만 사용했으며 자격증명은 출력하지 않았다.

- 실제 HTTP: 가상 160줄 파일 생성→업로드→처리 완료→재분석. 시간 변화 후보 1, 범위 안내 2. 전체 160건/HTTP 오류 80건/50%, bytes_out 8,016,000, bytes_in 누락을 확인했다.
- 후보 근거 API는 변화 창 80건만 반환했고 모두 HTTP500이었다. 전역 시간으로 통계를 좁히면 80건이었다. 공격 기법 매핑은 없었다.
- 실제 브라우저: 로그인/MFA→조사→출발지/목적지 통계→HTTP 상태 차트→시간 변화 탐지 설명→근거 80건(첫 페이지 50행)→원본 71번째 줄. status_code500 통계 행의 원본 버튼으로 이동하면 80건이 표시되고 필터가 유지됐다. 마지막에 필터를 해제했다.
- 실제 브라우저 CSV 다운로드 1050bytes. UTF8 BOM, 표시 그룹 1, 전체 160/오류 80/50%/전송량/누락/범위 일치 확인. SHA256 9cf659bb44c5f6ea66351aab096786f0e06e5b0e25784a066e759050f167252b. 원본 로그 내보내기가 아니다.
- 브라우저 도구의 초기 연결 시간 초과가 있었고, 복구 뒤 위 화면을 실제로 확인했다. 후속 성공으로 최초 시간 초과 원인 해결을 주장하지 않는다.
- 캡처 8장은 실제 554px 기본 화면의 원본 JPEG 바이트이며 편집/합성이 없다.

실제 사용 안내는 [STATISTICS-TEMPORAL-GUIDE.md](STATISTICS-TEMPORAL-GUIDE.md)이다. 이 데모는 SQLite/로컬 파일 저장소이며, 위 native 저장소 시험과 별도다. 브라우저를 실제 OpenSearch에 연결해 검증했다고 보고하지 않는다.

## 모델과 남은 범위

[8B 모델 가이드](MODEL-8B-KOREAN-SECURITY-GUIDE.md)는 Kanana1.5 8B Instruct를 첫 한국어 합성 비교 후보, Foundation-Sec-8B-Instruct를 영어 보안 특화 비교군으로 정리한다. Qwen3-8B는 별도 adapter, EXAONE7.8B는 업무 권리·adapter 조건이 필요하다. 공식 id/revision/config/tokenizer/template/권리와 원격 GGUF 지문을 분리했다.

준비 PC 고정 도구/모델 다운로드→변환→전용 모델팩→반입 검증/등록/합성 선택 명령을 작성했다. PowerShell 6개 예시 구문 검사 오류 0; 실제 실행은 아니다. 준비 PC Python/hf/wheel 완전 lock은 미확정 조건으로 명시했다.

**이번에는 새 가중치 다운로드·변환·추론·학습·한국어 SOC 평가·모델 교체를 하지 않았다.** 지정 Foundation BASE와 revision은 유지한다. 한국어와 보안 전문성 둘 다 충족하는 관제 품질이 입증됐다고 확정하지 않는다. 16GB에서 8B Q4와 OpenSearch의 공동 부하는 실측이 필요하다.

기존 10/12 설치 ZIP은 이번 소스 변경을 포함하지 않는다. 새 매체 제작/새 설치·재시작·LTSC17763 공동 접속/운영 인수는 남는다. 운영 자료·학습·관리자 설치·운영 모델 전환 승인은 유지한다.
