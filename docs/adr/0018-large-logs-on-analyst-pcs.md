# ADR-0018: 저사양 분석가 PC에서 대용량 TXT/CSV 처리

- 상태: Accepted
- 날짜: 2026-10-09

## Context
운영 환경은 서버가 아니라 **사양이 높지 않은 분석가 PC**(Windows 10 LTSC 2019, 폐쇄망)다. 브라우저·업무 프로그램과 OpenSearch(JVM)가 함께 돈다.
올라오는 증거는 대부분 TXT/CSV이고 크기가 크다(예: NDR 메타 검색 결과 CSV 600MB, 약 100만 행).
실측(59MB NDR CSV) 결과, 일반 CSV로 처리되어 탐지가 안 됐고, 파싱이 초당 216건이었으며, 분석 단계가 파싱보다 오래 걸렸다.
병목은 줄 읽기 O(n²), 이벤트마다 원본 줄·전체 열 저장, 줄마다 정규식 마스킹, 파라미터마다 전체 재조회, 문서 전체를 Python에서 파싱하는 조회였다.

## Decision
1. **형식 인식**: NDR 메타 CSV 전용 파서(요청·응답 짝짓기, 쿠키 값 미저장), 일반 CSV 열 이름 정규화(영문 변형·한글), 열 구성으로 data_source 추론, CP949·BOM·한국식 시간 형식.
2. **슬림 인덱스** (`SAW_RAW_STORE=auto`): 필드로 의미가 드러나는 소스(web/waf/zeek_*/suricata/pcap_*/ndr_http)는 `raw_event`를 저장하지 않고 `raw_ref`(파일·오프셋·바이트 길이·인코딩)만 저장. 상세·원문 보기·주변 줄은 증거 파일에서 읽어 오며, 파서가 지정한 마스킹(쿠키)을 다시 적용. 분류되지 않는 텍스트 로그는 원본 줄을 계속 저장(검색·drain3 패턴).
3. **지연 마스킹**: 원본 줄을 실제로 저장할 때만 마스킹 정규식을 실행.
4. **조회 투영**: 탐지기가 일부 필드만 읽을 때 SQLite는 `json_object(... doc -> path)`로, OpenSearch는 `_source.includes`로 필요한 필드만 가져온다. 파라미터 프로파일은 URI 패턴당 한 번만 훑는다. 텍스트 패턴(drain3)은 구조화 소스에서 돌리지 않는다.
5. **OpenSearch 단일 노드 튜닝**: 복제본 0, `best_compression`, bulk 5,000건/10MB. translog는 설치 프로필에 따름 — 혼자 쓰는 분석 PC(`-LocalOnly`)는 async 10초, 여럿이 쓰는 서버(기본)는 request(2026-10-10 변경: 공동 서버에서 "완료"가 디스크 기록을 뜻하도록).
6. **PC 자원 보호**: 무거운 작업 동시 1개(`SAW_JOB_WORKERS=1`), SQLite 페이지 캐시 64MB, IP 조회 캐시 상한 10만 개, NDR 짝짓기 대기 2만 건 상한.
7. **긴 작업**: 바이트 기준 진행률·남은 시간, 재시작 시 체크포인트(파서의 이벤트 방출 순서가 결정적이므로 이미 색인한 N건은 다시 파싱만 하고 색인하지 않음).
8. **설치 프로필**: `install.ps1 -LocalOnly` — 127.0.0.1 바인딩, 방화벽 규칙 없음, 메모리에 맞춘 힙 자동 산정.
   관리자 권한이 없는 PC는 `-NoAdmin` — 서비스 대신 사용자 프로세스(`saw-ctl.ps1`), `%LOCALAPPDATA%\SAW`, 현재 사용자 전용 ACL.
9. **Codex 재비교 채택**(2026-10-09): 체크포인트 경계 검증, 여러 줄 CSV 레코드, 처리 범위 보고서. Codex의 32MB·2만 건 고정 상한은 운영 로그 규모에 맞지 않아 채택하지 않음.

## Consequences
- 같은 59MB 파일: OpenSearch(힙 1GB) 기준 전체 약 35~40초(파싱+색인 약 20초, 초당 3,000건), 인덱스 약 20MB. 이전에는 파싱만 약 8분.
- 구조화 소스는 `raw_event` 부분 문자열 검색이 되지 않는다(필드 필터로 검색). 필요하면 `SAW_RAW_STORE=all`.
- 증거 원본 파일이 지워지면 구조화 이벤트의 원문 보기가 불가능하다(증거 보관 정책상 원본은 유지).
- 보류: 멀티 프로세스 파싱(4코어 PC에서 OpenSearch와 CPU 경합, 측정 후 결정), 업로드 시 수집 필터(정적 파일·기간 제외), 장비 직접 수집 커넥터.
