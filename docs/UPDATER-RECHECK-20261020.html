받아서 실행하는 순서

  1. GitHub 릴리스의 SAW-0.1.0-pilot.20261019-model-free-win-x64.zip을 받습니다. Source code ZIP은 설치 매체가 아닙니다.
  2. 아직 없는 새 폴더, 예를 들어 D:\SAW-update-20261019에 풉니다. 기존 C:\SAW와 원래 매체 D:\SAW-0.1.0을 보존합니다.
  3. UPDATE-SAW.cmd를 더블클릭합니다. 기존 설치 C:\SAW, 같은 드라이브의 새 복구 위치 C:\SAW-r-20261019를 선택합니다.
  4. 설치 점검을 누릅니다. 자동 검증이므로 수동 해시 비교는 필요 없습니다. 구형 설치가 원래 매체를 요구하면 실제 사용했던 전체 매체를 지정합니다.
  5. 분석가 접속·진행 작업을 정리한 뒤 중지 동의에 체크하고 업데이트 시작을 누릅니다.
  6. 완료 후 기존 계정·MFA로 로그인해 조사·증거·원문·노트를 확인합니다. 문제가 있으면 같은 창에서 검증된 복구본을 선택하고 이전 상태로 복구를 사용합니다.

복구는 백업 시점의 계정·자료·설정 전체를 되돌립니다. 그 이후 새 자료는 별도 보관하며 자동 병합하지 않습니다. ZIP·manifest·기존 릴리스는 교체하지 않았고 이번 재검증 문서만 추가합니다.
