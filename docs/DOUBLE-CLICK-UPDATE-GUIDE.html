1

새 매체를 별도 폴더에 준비합니다

  1. 받은 모델 제외 설치 ZIP을 폐쇄망으로 반입합니다.
  2. 파일 탐색기에서 ZIP을 D:\SAW-media-new에 압축 해제합니다. D:가 없으면 C:\SAW-media-new처럼 기존 설치 밖에 둡니다.
  3. 압축 해제한 폴더 안의 UPDATE-SAW.cmd를 더블클릭합니다. 확장자가 숨겨져 있으면 UPDATE-SAW로 보일 수 있습니다.
  4. 위 그림과 같은 SAW 기존 설치 업데이트 · 계정과 분석 자료 유지 창이 열리는지 확인합니다.

매체에 들어 있는 런타임을 사용합니다. 대상 PC에 Python이나 Node를 별도로 설치할 필요가 없으며, 설치 중 인터넷에서 파일을 받지 않습니다. 매체 무결성도 자동 검사하므로 긴 해시 값을 직접 비교할 필요가 없습니다.

2

폴더를 확인하고 ‘설치 점검’을 누릅니다

다음은 C:에 설치되어 있고 D:에 새 매체를 반입한 경우의 예입니다. 실제 사용하는 위치로 선택합니다.

기존 설치 폴더
C:\SAW현재 계정과 분석 자료가 있는 SAW 설치 폴더입니다.
새 매체 폴더
D:\SAW-media-new실행한 매체 위치가 자동으로 표시됩니다.
복구본 폴더

원래 매체 (선택)
D:\SAW-media-old구형 설치 이력을 확인하기 위해 프로그램이 요청하는 경우에만 선택합니다.

설치 점검을 누릅니다. 이 단계에서는 서버를 중지하거나 앱을 교체하지 않습니다. 설치 방식·파일·설정과 해당 설치의 프로세스인지 확인합니다. 실행 중인 자료 전체 복사 검사는 서버를 중지한 뒤 별도로 진행합니다.

일반 사용자 방식으로 설치했다면

NoAdmin 방식은 설치할 때 사용한 같은 Windows 계정으로 실행합니다.

Windows 서비스로 설치했다면

창의 안내에 따라 관리자 권한으로 열기를 사용합니다. 기존 서비스를 확인하며 새 서비스를 등록하지 않습니다.

복구본은 설치와 같은 드라이브에 둡니다.
C: 설치라면 복구본도 C:에 두되, C:\SAW 안이 아닌 별도 폴더를 사용합니다. 설치·매체·복구본을 서로의 하위 폴더에 넣지 마세요. 새 매체를 D:에 두어도 C:의 복구 공간은 필요합니다.

공간이 부족하다는 안내가 나오면 중단하고 여유 공간을 확보합니다. 기존 복구본을 지워서 강제로 진행하지 마세요.

3

분석 작업을 마친 뒤 업데이트합니다

  1. 공동 접속 중인 분석가에게 잠시 접속을 중단하도록 안내합니다. 업로드와 분석 작업이 끝났는지 확인합니다.
  2. 첫 번째 확인란인 분석가 접속·작업 정리와 서버 중지 동의를 체크합니다.
  3. 업데이트 시작을 누릅니다.
  4. 화면의 진행 단계와 안내를 확인하며 기다립니다. 진행 중에는 창을 닫거나 전원을 끄지 않습니다.
  1. 매체 확인
  2. 해당 설치의 서버 중지
  3. 전체 복구본 생성
  4. 새 앱 적용
  5. 서버 시작·접속 확인

자료가 많으면 복사와 검증에 시간이 걸립니다. 진행 막대는 실제 완료 백분율을 뜻하지 않습니다.

계정과 자료는 기존 설치에서 보존합니다.
계정·비밀번호·MFA·권한, PostgreSQL 자료, OpenSearch 색인, 원본 증거, 설정·키·인증서가 대상입니다. 새 관리자 계정을 만들거나 기존 비밀번호를 초기화하지 않습니다.

4

기존 계정으로 로그인하고 자료를 확인합니다

작업 완료 안내가 나온 뒤 SAW 열기를 누릅니다. 공동 접속 서버의 별도 호스트명을 사용한다면 기존에 사용하던 접속 주소로 직접 들어갑니다. 자동 열기는 로컬 HTTPS 주소만 지원합니다.

  • 기존 아이디·비밀번호와 MFA로 로그인할 수 있는지 확인합니다.
  • 업데이트 전에 보던 조사 목록과 분석 결과가 있는지 확인합니다.
  • 증거 화면과 원본 파일을 열어 확인합니다.
  • 공동 접속하는 분석가 PC에서도 기존 주소로 접속되는지 확인합니다.

서버의 기동 확인과 분석가의 업무 확인은 별개입니다. 위 항목을 확인한 뒤 사용을 재개하고, 복구본은 정해진 보관 기준에 따라 유지합니다.

5

문제가 있으면 이전 상태로 복구합니다

복구는 ‘전체 시점 복구’입니다.
업데이트 뒤 바꾼 비밀번호·MFA·권한, 새 조사와 업로드 자료도 백업 시점으로 돌아갑니다. 복구 직전 상태는 별도 보관 폴더에 남으며, 두 시점의 자료를 자동으로 합치지 않습니다.

  1. 같은 새 매체의 UPDATE-SAW.cmd를 다시 더블클릭합니다.
  2. 기존 설치 폴더를 확인하고, 복구본 선택으로 해당 업데이트가 만든 복구본을 선택합니다. 예: C:\SAW-r-20261018-153000.
  3. 분석가 작업이 끝난 뒤 서버 중지 동의를 체크합니다.
  4. 두 번째 확인란인 계정·자료를 이전 시점으로 되돌리고 새 기록을 자동 병합하지 않는다는 확인도 체크합니다.
  5. 이전 상태 복구를 누르고 복구·서버 접속 확인이 끝날 때까지 기다립니다.
  6. SAW 열기로 로그인하고 복구 시점의 계정·조사·증거 자료를 확인합니다. 화면에 표시되는 복구 직전 상태의 보관 폴더도 기록해 둡니다.

중간에 실패했다고 표시되면

설치 폴더와 복구본을 지우거나 덮어쓰지 않습니다. 실패 후 자동 삭제·자동 반복·자동 롤백은 하지 않습니다. 기록 폴더에서 안전한 상태 기록과 오류 코드를 확인할 수 있습니다.

서버 시작 실패가 업데이트 미적용을 뜻하지는 않습니다. 이미 앱이 바뀌었을 수 있습니다. 설치본 다시 시작은 설치 확인을 거쳐 다시 시작하려는 경우에만 사용합니다.
